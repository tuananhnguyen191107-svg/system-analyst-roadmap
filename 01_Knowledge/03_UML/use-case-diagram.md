## 1. Tổng quan
**Use Case Diagram** là sơ đồ mô tả các chức năng
mà hệ thống cung cấp cho các tác nhân bên ngoài.

## 2. Các thành phần chính

| Thành phần | Ý nghĩa |
|---|---|
| Actor | Tác nhân tương tác |
| Use Case | Chức năng hệ thống |
| Association | Quan hệ tương tác |
| Include | Hành vi được bao gồm |
| Extend | Hành vi mở rộng có điều kiện |
---
## 3. Ví dụ thực tế

### Hệ thống quản lý thư viện

**Actor:** Sinh viên

**Các Use Case:**
1. Tìm kiếm sách.
2. Đăng ký mượn sách.
3. Xem lịch sử mượn.
